# 越泰指南 Codex SEO 內容工作流

這份文件定義之後如何讓 Codex 協助自動蒐集公開資訊、整理 SEO 文章草稿，並保持人工審核。

## 核心原則

- Codex 可以協助研究、整理、產出草稿，但不能直接發布未審核內容。
- 每篇內容都要記錄資料來源、最後更新日期與需要人工確認的欄位。
- 旅遊文章以實用性為主，商務文章以可信任與可聯絡為主。
- 餐廳、景點、商家資訊要優先使用官方網站、官方社群、Google Maps 公開資訊、政府或商會公開資訊。
- 價格、營業時間、簽證與交通政策容易變動，發布前必須再次確認。

## 任務欄位

每個研究任務至少包含：

- 目標關鍵字
- 搜尋意圖
- 目標讀者
- 城市或國家
- 內容類型
- 必蒐集來源
- 建議大綱
- SEO 檢查項目
- 審核狀態

## 產出格式

Codex 產出的草稿應包含：

- SEO Title
- Meta Description
- Slug
- 摘要
- 文章目錄
- 正文
- FAQ
- 圖片需求與 alt 建議
- 內部連結建議
- 商家名錄連結建議
- 結構化資料類型
- 來源清單
- 人工確認清單

## 內容優先順序

第一階段：

- 城市總指南
- 餐廳推薦清單
- 景點推薦清單
- 在地生活指南
- 台商商務接待指南

第二階段：

- 單一餐廳頁
- 單一景點頁
- 單一商家頁
- 台商專訪
- 中文服務商家清單

## 審核清單

- 標題是否包含目標城市與主要關鍵字
- 是否回答搜尋者真正要解決的問題
- 是否有最後更新日期
- 是否有 FAQ
- 是否有內部連結
- 是否有商務合作或商家名錄導流
- 是否避免捏造價格、營業時間與地址
- 是否標註仍需人工確認的資訊
