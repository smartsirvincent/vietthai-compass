The ROAST photograph's title incorrectly includes Chiang Mai. Branch identity was cross-checked against the photograph on https://www.roastbkk.com/location/emquartier/: the same wooden facade, ROAST lettering, suspended shelving, counter and floor are visible. The official photograph was used for verification only, not republished.

The T&K file is retained as the original downloaded JPEG, without edits, and rendered with `object-fit: contain`. Other selected files were converted to WebP with no enlargement. Visible credits include date context so historical photos are not presented as current conditions.

Ten other businesses remain unresolved. A Hua Seng Hong Flickr candidate did not establish the Yaowarat branch. Other Openverse results were unrelated places or different branches. Do not publish those as matching storefronts. The admin pending-photo list now reads the current Thai CMS records, including manual uploads, instead of a static manifest-derived count.

No Vietnamese records, descriptions, contacts, tags or reviews are changed by this photo import.
